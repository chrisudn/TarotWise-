## 1. 單卡抽牌 (Single Card Pull)

**張數**：1 張

**適用場景**：
- 每日指引 (Daily guidance)
- 快速解答
- 冥想焦點
- 心情 check-in

**牌位說明**：

| 位置 | 意義 |
|------|------|
| 1 | 當下最需要的訊息 / 整體指引 |

**變化題型**：
- 「今天需要注意什麼？」
- 「這件事的簡單建議？」

---

## 2. 三張牌陣 (Three-Card Spread)

**張數**：3 張

**適用場景**：最受歡迎的基礎牌陣，適合多數問題

### 變體 A：過去 / 現在 / 未來

| 位置 | 意義 |
|------|------|
| 1 (左) | 過去 — 導致目前狀況的原因 |
| 2 (中) | 現在 — 當下的情況 |
| 3 (右) | 未來 — 可能的發展方向 |

### 變體 B：狀況 / 障礙 / 建議

| 位置 | 意義 |
|------|------|
| 1 | 狀況 — 目前問題的核心 |
| 2 | 障礙 — 面臨的挑戰或阻力 |
| 3 | 建議 — 行動方向的指引 |

### 變體 C：心 / 腦 / 行動

| 位置 | 意義 |
|------|------|
| 1 | 心裡感受 — 情感層面 |
| 2 | 理智思考 — 思維層面 |
| 3 | 行動建議 — 實際做法 |

---

## 3. 五張牌陣 (Five-Card Cross)

**張數**：5 張

**適用場景**：需要比三張牌陣更深入的分析

| 位置 | 意義 |
|------|------|
| 1 (中) | 狀況 — 問題的核心 |
| 2 (下) | 挑戰 — 潛在的困難 |
| 3 (上) | 建議 — 最佳行動方向 |
| 4 (左) | 隱藏影響 — 未知因素 |
| 5 (右) | 結果 — 可能的 outcome |

**變體 — 愛情五張**：

| 位置 | 意義 |
|------|------|
| 1 | 你對這段關係的看法 |
| 2 | 對方對這段關係的看法 |
| 3 | 關係的優勢 |
| 4 | 關係的弱點 |
| 5 | 未來發展建議 |

---

## 4. 馬蹄鐵牌陣 (Horseshoe / 七張牌陣)

**張數**：7 張

**適用場景**：事件發展全貌、人生規劃、一週展望

| 位置 | 意義 |
|------|------|
| 1 | 過去 — 事件的起因與背景 |
| 2 | 現在 — 當下的處境 |
| 3 | 隱藏影響 — 未知或潛意識因素 |
| 4 | 障礙 — 需要克服的挑戰 |
| 5 | 他人影響 — 外部人或環境的影響 |
| 6 | 建議 — 應該採取的方向 |
| 7 | 結果 — 最終發展 |

---

## 5. 凱爾特十字 (Celtic Cross)

**張數**：10 張

**適用場景**：最全面的經典牌陣，重大人生抉擇、深度自我探索

| 位置 | 意義 |
|------|------|
| 1 (中) | 現狀 — 問題的核心 |
| 2 (橫跨) | 挑戰 — 交叉的障礙或影響 |
| 3 (下) | 基礎 — 潛在的根基 / 過去基礎 |
| 4 (左) | 近期過去 — 正在淡出的影響 |
| 5 (上) | 最佳可能 — 可顯化的最佳結果 |
| 6 (右) | 近期未來 — 即將到來的階段 |
| 7 (右下1) | 你的態度 — 你如何處理此事 |
| 8 (右下2) | 外部影響 — 環境與他人 |
| 9 (右下3) | 希望與恐懼 — 渴望與擔憂 |
| 10 (右下4) | 最終結果 — 走向何方 |

    [7]
