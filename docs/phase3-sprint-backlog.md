## Sprint 7：凱爾特十字牌陣

**Sprint Goal**：使用者可使用完整的 10 張凱爾特十字牌陣。

**預計工時**：5 個工作天

### Task Breakdown

| # | Task | 預估時數 | 依賴 |
|---|------|---------|------|
| T7-1 | 型別擴充：`SpreadType` 新增 `celtic-cross` | 0.5h | - |
| T7-2 | 牌陣定義資料（10 個牌位、十字 + 杖佈局） | 1.5h | T7-1 |
| T7-3 | 凱爾特十字牌陣元件（`/components/spread-celtic-cross.tsx`） | 5h | T7-2 |
| T7-4 | 牌陣選擇器擴充為 5 選項 | 0.5h | T7-1 |
| T7-5 | 牌陣說明頁擴充（含凱爾特十字） | 0.5h | T7-2 |
| T7-6 | 首頁流程串接 + RWD 測試 | 1h | T7-3 ~ T7-5 |

### 凱爾特十字佈局

```
        ┌──────┐
        │  5   │ 展望 — 最佳情況
     ┌──┤      ├──┐
     │  └──────┘  │
     │   ┌──────┐ │
     │   │  1   │ │
  ┌──┴──┤      ├──┴──┐
  │  3  │  2   │  4  │
  │ 基礎│ 阻礙 │ 過去│
  └──┬──┤      ├──┬──┘
     │  └──────┘  │
     │   ┌──────┐ │
     │   │  6   │ │
     │   └──────┘ │
     └──┐      ┌──┘
        └──────┘
           7→8→9→10（杖）
```

| 位置 | 意義 |
|------|------|
| 1 (中) | 現在 — 目前的處境與核心問題 |
| 2 (橫) | 阻礙 — 眼前的困難與挑戰 |
| 3 (下) | 基礎 — 潛意識與過去根基 |
| 4 (右) | 過去 — 近期事件與影響 |
| 5 (上) | 展望 — 最佳可能性與目標 |
| 6 (左) | 未來 — 近期發展方向 |
| 7 | 自我 — 個人的態度與能量 |
| 8 | 環境 — 外部影響與他人看法 |
| 9 | 希望/恐懼 — 內心的渴望與擔憂 |
| 10 | 結果 — 最終發展與總結 |

### Acceptance Criteria

| # | 條件 | 測試方式 |
|---|------|---------|
| AC7-1 | 牌陣選擇器新增凱爾特十字選項 | 視覺確認 |
| AC7-2 | 佈局正確：十字 6 張 + 杖 4 張 | 對照標準圖 |
| AC7-3 | 10 個牌位標籤與說明皆正確 | 逐一核對 |
| AC7-4 | 可依序翻完 10 張牌 | 操作測試 |
| AC7-5 | 翻牌節奏流暢（每次點擊翻一張） | 操作測試 |
